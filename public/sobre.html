03 / CONHEÇA A TECNOLOGIA

Proteção com inteligência.

O FoxSecure é um projeto de cofre automatizado que une programação, eletrônica e Internet das Coisas.

01 — ESTRUTURA

Uma caixa feita sob medida

A estrutura externa do cofre está sendo desenvolvida com uma impressora 3D. Essa escolha permite criar uma peça personalizada, com dimensões e encaixes pensados para receber os componentes eletrônicos.

02 — CONTROLE

O ESP32 como centro do sistema

O ESP32 é a placa responsável pelo controle eletrônico e pela comunicação em rede. Ele recebe comandos autorizados do sistema e coordena a abertura do mecanismo.

03 — MECANISMO

Acionamento por microservo

Quando o código é validado, o sistema envia uma solicitação ao ESP32, que aciona um microservo conectado ao mecanismo de abertura do cofre.

04 — EXPERIÊNCIA

Desafio de quatro dígitos

O visitante resolve quatro charadas, cada uma relacionada a um dígito. O sistema permite até três tentativas. Após três erros, a conta é bloqueada até que o administrador a libere.
